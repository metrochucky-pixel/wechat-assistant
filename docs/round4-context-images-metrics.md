# 第四轮：上下文、看图复用和回放统计

2026-10-04，codex/bot-round4，接续后台计算与任务路由。

## 上下文

日常文本拟答与复杂视觉拟答均使用 `conversation_context`。当前问题、补充约束保持完整。历史只查询完全一致的会话显示名，不通过人物名串其他群；按话题重合筛选、同一提问者优先，最多4项、1800字符，整条装入，避免半句摘要改变含义。提问者不同明确标注，不能合并经历或要求。近期当前群的三条短回复作为防重复提示。相关屏幕文字预算2200字符，未选入的消息有数量标记；这只影响拟答上下文，不替代完整的新消息观察、取消检查和发送授权。

只有确认发送的交互进入结构化历史；保留30天、全局最多1000项。旧记忆只有完全相同会话键且话题相关时才作为未知提问者背景。停止向事项拟答注入旧梗列表，运行中的 `voice.md` 仍是原有风格标准。知识问答继续只使用已选问题与完整补充条件，不塞入无关聊天历史。

## 图片

不再要求几轮以前的整张聊天截图像素完全不变。先重新核对当前会话与待答事项，再在新画面中定位图片发送者和上下文，验证候选裁剪、打开后的同图关系、原图加载状态和必要的细节放大。无法确定唯一目标时仍不能猜图。现有最多两次技术恢复和跨群调度保留；不请机主处理截图移动等技术故障。

取得原图证据后，图片事实以“群 + 完整问题/上下文/提问者 + 完整原图画面序列 + 放大画面 + 缓存版本”做精确哈希。仅排除顶部4.5%的系统状态栏；不按缩略图、近似外观或旧坐标命中。有效期24小时、最多200项。只缓存足以回答该问题的 observed/text/uncertainty，不能缓存发送授权或最终回复。命中后重新拟答，仍经过版本与发送前核验。不同问题或画面变化会重新分析；这是有意保守的复用范围，不宣称所有相似图片都能命中。

后台 worker 与同步回退路径均已接入；缓存只存事实文本与哈希，不额外保存原图文件。

## 回执统计与升级回放

`python3 tools/reply_status.py` 只读本地数据库，不输出聊天原文。新增回执记录与 jobs 的 sent 状态一起提交，每个任务只记一次。计时优先从问题来源消息第一次被程序观察开始，包含等待、生成、再次巡检、发送和回执确认。无来源事件时明确标记 request_observed 或 job_created。输出最近24小时 P50/P95/最大值、样本数、同一事件的多任务回执数、超期未完成候选、技术跳过及任务状态。统计故障不会撤销已经确认的发送。

不把后台生成完成计为发出，不把 uncertain 计为成功；上线之前的发送没有新回执样本，不回填伪造精确时间。两分钟以上的 open 且可处理事项是排查候选，不等于漏答；漏答率与误判率没有人工标注就保持未知。该报表也不能证明未被读取的消息没有遗漏。

升级门禁：`python3 tools/check_upgrade.py`。任何测试或回放失败返回非零退出码。包括185项离线回归检查，以及由本机7个历史会话导出的35项结构回放检查。历史夹具只保留顺序、重复关系、发送者区分和提及标记，不含聊天原文、群名或成员名；回放验证首次读取不重播、重复读取身份稳定、追加新消息只记一次。取消、改问、仅@、发送不确定、接口超时等由已有确定性回归覆盖。脱敏结构回放不测模型的语义判断正确率。

重新生成本地历史夹具：`python3 tools/replay_history.py --db /path/to/wechatbot/outbox.sqlite3 --export tools/fixtures/history_structure.json`。源库只读，回放使用独立临时库，无模型请求、无设备操作。

## 部署验证边界

部署前跑完整门禁，确认无发送中任务，停止唯一手机进程、取得设备锁后备份并替换变更文件，再启动服务并检查新版本日志、单进程和当前 ADB device。没有为了测试向真实群发送消息。新回执统计需要上线后的实际发送积累样本，不把启动成功当成完整发消息验证。
