# 微信 bot 向机主确认

使用已有飞书通知机器人私聊。遇到身份关系、个人安排、真实报价和承诺等需要机主决定的事项，暂停该事项并写入 SQLite。主进程启动独立监听线程，每 15 秒尝试通知、读取机主回复；模型慢或微信扫描阻塞不会卡住这个线程。

每条确认单包含编号、群名、问题、疑点和拟回复。支持：

- `#001 照发`：采用确认单里的拟回复；没有拟回复时拒绝。
- `#001 改成 你的原话`：以指定文字恢复该任务。
- `#001 补充 背景信息`：仅加入本事项背景，重新拟稿后另发确认单。
- `#001 跳过` / `#001 我自己回`：停止该事项自动回复。

只接受配置机主 open_id 在通知所在私聊中的 text 消息。按 message_id 去重，拒绝早于问题创建时间的指令。批准时核对 job、事项修订号及挂起原因。已经发送、发送结果不明、已有手机草稿、事项变化或超过一天的事项不会自动恢复。恢复后仍经过群身份、最新消息、修订、发送结果校验；群里问题取消、修改或断档会阻止旧答案发送。MentionOnly 继续要求原事项存在有效 @ 授权。

普通知识问题自动走现有问答 API，不让机主选择模型。陌生群友普通问候不需要查身份；只有确实影响回答的关系信息才询问。补充不写入永久人物档案；长期资料仍由机主明确要求后更新。

问题、通知、指令处理结果持久化在 outbox.sqlite3 的 owner_questions / owner_receipts / owner_meta。发送使用持久化 UUID 去重，失败保留待通知并退避。机主不答复不会自动照发。测试单只有收发验证用途，不能创建微信群回复。

实现：owner_review.py；入口：wechat_autoreply.owner_reviews / _ask_owner。回归：tools/test_owner_review.py。
