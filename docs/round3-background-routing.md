# 第三轮：后台生成与任务级模型路由

2026-10-04，codex/bot-round3。手机进程仍独占设备；拟答、知识查询、取得原图后的理解/拟答、生成图片进入持久队列，最多2个独立计算进程，队列最多8项。提交不等答案，手机可继续观察其他会话。控制手机的模型取证（定位原图、确认页面等）仍在手机进程，不能并行点击设备。

后台进程禁用ADB、截图、点击、发送及通知。它只写独立结果文件和模型健康统计，不修改微信发送任务。结果绑定任务ID、完整任务内容摘要、问题版本及授权；取消、版本变化、已发送或发送未确认时停止计算/丢弃结果。结果交回后仍进入原先的最新消息观察、事项核验、发送事务和回执检查。后台超时不会将任务标记为完成，也不直接通知机主确认。复杂任务失败保留原任务类别，不能降成普通闲聊后发送未经查证的答案。

手机进程重启后，未完成计算标记失败，重新观察后按已有技术恢复规则处理；孤立计算进程检测父进程退出后终止。后台自身有硬时间预算，监督线程另有强制终止保护。排队和结果超过180秒不再接受。原始截图/输入在任务结束时删除，任务结果保留在权限受限的本地数据库；启动时清理7天以前记录。未向公开仓库推送私有群信息。

| 类型 | 计算总预算 | 单次接口上限 | 最多尝试 |
|---|---:|---:|---:|
| 简单闲聊 | 18秒 | 9秒 | 2 |
| 知识查询 | 60秒 | 22秒 | 3 |
| 图片理解/复杂拟答 | 40秒 | 15秒 | 3 |
| 手机取证/列表读取 | 25秒 | 12秒 | 2 |
| 生成图片 | 65秒 | 25秒 | 2 |

总预算覆盖整个任务中的降级链，内部调用不重置预算。简单拟答识别为复杂问题后，通过新版本任务切换复杂拟答预算；不强行在简单路由里不断重试。模型排序参考同类任务最近15分钟耗时和失败记录，并遵守已有供应商冷却。候选集按能力限定：实时问题直接进入带检索与引文验证的接口，不拿普通文本回答冒充查证结果；普通知识允许文本模型快速回答，明确需要联网才升级。明确“不涉及价格”等排除条件不单独触发联网。

`WECHATBOT_BACKGROUND=0` 可回退原同步生成流程；发送检查不受开关影响。只读状态：`python3 tools/background_status.py`，显示任务阶段、状态、错误类型和模型耗时，不输出提示词或密钥。性能记录将等待计算标为 background_pending，避免误认为技术失败。

验证：165项相关离线测试通过（后台与路由20、图像18、技术恢复7、可靠性30、性能14、知识问答5、调度13、会话集成13、联网证据6、机主反馈10、话题规划29）。覆盖真实子进程快慢任务并行、队列/并发上限、任务去重、版本变化/取消/发送不确定、总预算强杀、重启失效、私有取证清理、后台禁用手机、原图取得后先返回聊天再生成、已有发送入口保留、模型健康排序及来源路由。

真实接口离线验证使用临时数据库，不操作手机、不发送消息：提交约0.7毫秒返回；一次带来源查询19.07秒完成；普通知识文本路由2.96秒完成（接口约2.55秒）。两次都未改写发送任务的回复内容。这验证后台计算与路由，不代表真实群聊从发现消息到确认发送的完整延迟。
