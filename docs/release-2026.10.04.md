# 2026.10.04 发布说明

整合第一轮到第五轮优化，以及长期记忆、发送预算隔离、自然语言反馈学习和未读发现修复。基于已部署的修复版本，公开版另将个人昵称、群策略和设备回退配置化，默认影子模式，并增加启动入口、依赖清单、构建工具和文档。

## 验证范围

18 组离线检查及 35 项脱敏历史结构回放通过；最新四项修复包括 16 项针对性回归。运行中的手机已在线并完成新版本会话检查。未用虚构消息向真实群测试，尚不能据此承诺端到端响应时间或长期漏答率。

## 升级现有 Mac 部署

1. 校验 ZIP 的 SHA-256，解压到独立目录，安装依赖并运行 `tools/check_upgrade.py`。
2. 确认没有正在发送的消息或后台计算；停止现有服务并确认 `.phone-owner.lock` 已释放。当前部署的服务名是 `com.chuck.wechatbot`。
3. 备份现有代码、私人配置和 SQLite（使用 SQLite backup API，避免直接复制活动中的 WAL 数据库）。备份应只保存在受限的本地目录。
4. 将发布包源码复制到部署目录，保留既有个人资料、密钥、数据库和消息状态。不要用整目录删除/替换抹掉运行数据，也不要改变既有发送开关。
5. 启动原服务，检查单一进程、ADB `device`、新日志及真实巡检。发送是否成功要看新消息回执，不能只看启动成功。

## 回滚

停止服务并获得手机锁后恢复上一版代码，再启动原服务。保留最新消息状态数据库，避免把已经发送的消息恢复成待发送状态。仅在有针对性的数据库恢复方案时才恢复数据库备份；不要将“回滚代码”等同于“回滚消息事实”。

公开版更新不改动当前手机上的私人部署。现有部署升级公开版前，必须迁移实际昵称、群策略、设备参数及启动命令（实发需 `tools/run_bot.py --send`）。
