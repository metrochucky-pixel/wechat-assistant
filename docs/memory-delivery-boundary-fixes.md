# 发送与记忆边界修复

2026-10-04，接续长期记忆版本。本文件中的预算取代上一轮的整次访问45秒限制。

1. 普通观察仍为45秒/5次模型调用；只有进入文本发送、图片发送或未确认发送的回执核对时，才一次性切换为发送阶段75秒/12次调用，单次接口最多10秒。整次访问最多120秒，调用者设置的更短硬期限也必须遵守。后续preflight和receipt共享发送预算，反复进入发送函数不能补充次数或延长期限。不简化任何身份、草稿、事项版本或回执检查。超时仍保留发送状态，不直接重发。
2. sending/uncertain/prepared仅暂停新样本的来源确认，记为pending_origin，解决事务后再依据同一可见事件重新判断。历史样本只在内容与记录中的bot写入相似、且观察时间落在该任务创建前10秒至最后更新后120秒时才排除；不因群里另一条消息尚未确认而撤销历史。由于同账号没有绝对作者标识，来源仍为保守推断，不用于个人事实或授权。
3. 自动新增的避免词存入owner_avoid_evidence，逐词逐事件记录来源。渲染时与人工明确词表合并去重；某个样本失效只撤销该来源，其他来源仍保留该词。手动停用avoid_words会阻止整类规则加载和自动恢复。其他标量偏好（长短/表情）仍以明确人工规则为先。
4. 屏外查找的每一页都检查@标记，先持久保存发现，再返回当前页带新坐标的@会话和目标会话，优先处理@。即使目标尚未找到也停止继续翻页，处理新发现的@；发现记录不授予发送权限，仍需正文@证据和原有事项核验。

验证：新增14项边界回归，完整门禁226项测试加35项脱敏结构回放。包括调用实际send_reply函数的隔离测试：观察预算已耗尽5次后，完整执行7次发送阶段取证调用并得到模拟回执；所有手机操作与接口均隔离，没有真实发消息。覆盖发送预算不可重置、外层短期限、历史样本保留、来源延后确认、逐词追加/撤销、多来源保留以及途中@持久化/优先处理。
